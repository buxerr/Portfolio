# Retro Pixel Portfolio

This is a complete Vite + React + Tailwind project scaffolded from your uploaded `retro_pixel_portfolio.jsx` file.
Your component is in `src/App.jsx`. Tailwind is already set up. Images referenced in the project
use the `/assets/...` path under `public/assets`.

## Getting started

```bash
# 1) Install dependencies
npm i

# 2) Start the dev server
npm run dev

# 3) Build for production
npm run build

# 4) Preview the production build
npm run preview
```

## Notes

- I replaced occurrences of `/mnt/data/` with `/assets/` so you can drop any images into `public/assets`.
- If an image is missing, the UI gracefully falls back to a generated pixel thumbnail.
- You can change the project title and metadata in `index.html`.
